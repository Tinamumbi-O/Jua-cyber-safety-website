 Jua — Cyber Scam Awareness Assistant

Helping people recognize online scams and make safer digital decisions.**

 About the Project

Jua is a cyber-safety awareness website featuring an embedded AI assistant that helps users explore online scams, understand digital risks, and learn safer online practices.

This project combines front-end web development with an AI chatbot to make cyber-safety information more accessible.

 Features

- Interactive AI-powered cyber-safety assistant
- Educational focus on online scams and digital awareness
- Custom website interface and branding
- Live deployment for visitors to explore

 Technologies

HTML5— website structure
CSS3— layout and styling
JavaScript— website interactions, where implemented
Jotform AI Agent — chatbot integration
Netlify- website hosting
